01-plot_ATAC_open_close_peak_CG_methylation_ratio_boxplot.ipynb: This script is used to generate boxplots of 5hmCG, total 5mCG, and true 5mCG ratios in ATAC open and closed regions across different subclasses to visualize the differences in methylation levels between aging and young mice. The script first defines input and output paths, reads files from specific directories, extracts methylation data for each subclass, and calculates mean differences and standard deviations. Finally, it uses the ggplot2 library to plot boxplots, providing a visual representation of methylation changes in open and closed peaks across different subclasses, which helps reveal the dynamic patterns of DNA methylation during aging.
