00-ATAC_peak_slop3kb.sh: Primarily expands the cell type-specific CREs of ATAC by 3000 bp on each side from the center point.
02-plot_boxplot_5hmC_total5mC.ipynb: This script is used to generate boxplots of 5hmC and total 5mC methylation ratios in promoter and gene body regions across different subclasses to compare the differences between aging and young mice. The script first reads genomic annotation files (such as promoter and gene body regions), then iterates through multiple input directories to extract methylation data for each subclass and calculate the differences. Finally, it uses the ggplot2 library to plot boxplots, providing a visual representation of methylation changes in open regions across different subclasses, which helps reveal the dynamic patterns of DNA methylation during aging.
02-plot_boxplot_true5mC.ipynb: This script is used to generate boxplots of true 5mC methylation ratios in promoter and gene body regions across different subclasses to compare the differences between aging and young mice. The script first reads genomic annotation files (such as promoter and gene body regions), then iterates through multiple input directories to extract methylation data for each subclass and calculate the differences. Finally, it uses the ggplot2 library to plot boxplots, providing a visual representation of methylation changes in open regions across different subclasses, which helps reveal the dynamic patterns of DNA methylation during aging. Additionally, the script integrates ATAC-seq and DNA methylation data to analyze methylation levels in open peaks across different subclasses, offering a visual support for studying age-related epigenetic changes.
The shell scripts from 01 (including cmd or scale) are used to generate DNA methylation ratio for specified bed intervals.
