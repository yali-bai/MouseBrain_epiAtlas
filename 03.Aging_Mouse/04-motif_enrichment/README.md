01-generate_specific_subclass_hyper_hypo_DHMR_DMR.ipynb: This script identifies subclass-specific differential hydroxymethylated (DHMR) and methylated (DMR) regions. It reads input CSV files containing hyper/hypo modification states for each subclass, filters out regions shorter than 200bp, then compares across subclasses to retain only subclass-unique hyper/hypo regions. The final output includes CSV files listing the specific regions and their counts for each subclass, which are intended for downstream analysis.
02-generate_subclass_hyper_hypo_DHMR_DMR.ipynb: This script summarizes all hyper- and hypo-modified regions within each subclass from DHMR and DMR datasets, without filtering for subclass specificity. It reads in subclass-level methylation state data, filters out regions shorter than 200bp, and then groups by subclass to count and list all hyper/hypo regions. The results are written to CSV files listing the regions and counts for each subclass, which can be used in downstream visualization or enrichment analyses.
03-motif_enrichment_analysis_segment_background_regions.py: This script performs transcription factor motif enrichment analysis on subclass-specific regions versus background regions. It first loads the background regions file and removes any overlapping regions with subclass foreground regions to ensure background independence. Then, motif annotation is performed on both subclass and background regions using bedtools. Fisher’s exact test is applied to calculate the enrichment significance of each motif in subclass regions compared to background, followed by multiple testing correction. The script outputs a results file containing enrichment statistics for each motif, facilitating downstream functional analysis and interpretation.
03-motif_enrichment_analysis_segment_background_regions.sh: This bash script automates the batch submission of motif enrichment analysis jobs. It requires four input arguments: an input CSV file, a background region file, a specific region type (e.g., Specific_Hyper_Region), and a group identifier (e.g., DHMR or DMR).
04-Lollipop_chart_motif.ipynb: This notebook analyzes and visualizes the enrichment of EGR1 binding motifs across different cell subclasses. It begins by loading differential hypermethylated regions (DHMR) data associated with EGR1 motifs and calculates the proportion of subclasses containing these motifs. Using a predefined order of cell subclasses, the data are merged and adjusted p-values are transformed with -log10 to measure statistical significance. The script further integrates hyper- and hypomethylated region statistics to plot lollipop charts where point size represents the number of enriched regions and color indicates the percentage or odds ratio of enrichment. Significance threshold lines are added to the plots, and color gradients highlight subclass differences. The final visualization is saved as a PDF file. This comprehensive workflow combines data processing, statistical evaluation, and multi-dimensional visualization to clearly depict the distribution of EGR1 binding motifs in aging-related epigenetic regions.
