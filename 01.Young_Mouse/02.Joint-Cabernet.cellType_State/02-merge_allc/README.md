### "01-allc_paths_for_class_and_threeclass.ipynb" and "01-get_allc_txt_for_subclass.ipynb"
These two scripts are for getting the allc table (a file contains 1 ALLC path in each row).
Note that the subclass-level merged allc files are generated by merging single-cell allc files, while the class-level and threeclass-level merged allc files are generated using subclass-level merged allc files.
Thus, the allc tables for subclass-, class- and threeclass- level allc file merging, are generated in different ways.

#### "02-allcools_merge_subclass_5hmC.sh", "02-allcools_merge_subclass_5mC.sh", and "02-allcools_merge_class_threeclass.sh" 
These three scripts are for merging the allc files at different clustering levels.
These are the bash files that actually carry out the merging process using the generated allc tables.
