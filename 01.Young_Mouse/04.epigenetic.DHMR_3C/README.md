### "01-A_B_compartments" 
This script analyzes the methylation rate of A and B compartments.

### "02-loop_calling_with_chromosight" 
This script conducts the calling of 3C loops with chromosight. These loops (dots) are the basis for further integrated analysis using both 3C data, DNA methylation data, and RNA expression data.

This script analyzes the potential regularoty function of distal methylation status (especially 5hmCG).
