#### 01-QC_plot.R: 
script to draw histogram plot of hmCG(H), mCG(H)_hmCG(H) level of mm10 and hmCG, mCG_hmCG level of spike-in

#### 02-plot_normalized_read_counts_across_read_mCH_ratio*: 
scripts to draw normalized read counts across read mCH ratio and read ratio after CH filter

#### 03-QC_boxplot_and_violin_plot.R: 
script to generate a series of quality control plots, including violin plots depicting raw/mapped read distributions, genebody and gene counts, as well as boxplots comparing key metrics (genome coverage, detected CG sites, gene number) among the three sequencing technologies

#### 04-UMAP_plot_of_read_counts.R: 
script to draw UMAP of Raw and Mapped reads of RNA, 5hmC, 5mC_5hmC
