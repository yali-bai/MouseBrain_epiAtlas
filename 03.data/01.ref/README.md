### gene_CpG_number_metainfo.csv: 
Gene CpG number of all genes,containing geneid, location, CpG number, gene length, genename information.

### mm10.chrom.sizes.nochrM.txt: 
Mouse chromosome length with Chr M. Likewise, the first column is chromosome number and the second column is chromosome length.

### PromoterUp2k.mm10.bed:  
Bed file of all genes in promoter region (2k upstream of the TSS sites), containing chromosome number, start, end, gene id, gene name and strand information.

### mm10.genes.bed:  
Bed file of all genes in reference genome, containing location, id, plus and minus chain and name of genes in genebody region, and gene type.
