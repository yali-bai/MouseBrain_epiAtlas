### Zhuang_raw_counts.rds: 
seurat object of Zhuang MERFISH data containing expression matrix and meta-information of cell id, cell type, sex.

### zeng_v3_metadata.rds: 
meta information of Zeng 10X RNA cells used in integration with Joint Cabernet dataset, containing cluster alias, cell id, brain region, class label and subclass label. The celltype label was used when we perform label transfer.

### cell_metadata_Zhuang_MERFISH.csv: 
meta-information of Zhuang MERFISH cells, which contains cell id, donor information, cluster alias, spatial location of sampling. We used "z" column to select samples of similar spatial location with Joint Cabernet brain slice dataset.
