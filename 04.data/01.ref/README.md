### mm10.chrom.sizes.nochrM.txt: 
Mouse chromosome length without Chr M. The first column is chromosome number and the second column is chromosome length.

### mm10.chrom.sizes.txt: 
Mouse chromosome length with Chr M. Likewise, the first column is chromosome number and the second column is chromosome length.

### mm10.genes_duplicated.bed: 
mm10 gene bed file with column names containing chromosome number, start, end, gene id, gene name, gene type and strand information.

### PromoterUp2k.mm10.bed:  
Bed file of all genes in promoter region (2k upstream of the TSS sites), containing chromosome number, start, end, gene id, gene name and strand information.

### chrom_info_100k.csv: 
the genomic coordinates of mm10 chromosomes partitioned into 100 kb bins. The first column is chromosome number and order, the second column is chromosome number, the third column is the end site, and the forth column is the start site.

### Gene.output.bed.gz: 
Compressed file of bed file of all genes in reference genome, containing location and CpG quantity of genes.
